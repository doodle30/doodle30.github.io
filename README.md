# doodle30.github.io (도메인 루트)

GitHub 사용자 사이트 저장소 `doodle30/doodle30.github.io`에 올릴 파일이다.
실제 홈페이지는 `doodle30/Homepage`(`/Homepage/`)이고, 이 저장소는 도메인 루트에만 있어야 하는 파일을 담는다.

| 파일 | 역할 |
|---|---|
| `app-ads.txt` | AdMob 승인 판매자 선언. 크롤러는 도메인 루트(`https://doodle30.github.io/app-ads.txt`)만 본다 |
| `index.html` | 루트 접속을 `/Homepage/`로 보냄 |
| `.nojekyll` | Jekyll 처리 끄기 |

- 게시자 ID `pub-1845740075718185`는 빨간펜 무쌍 AdMob 앱 ID(`ca-app-pub-1845740075718185~…`)에서 왔다. 같은 AdMob 계정의 게임은 이 한 줄로 모두 덮인다.
- `f08c47fec0942fa0`은 Google의 고정 인증 ID다.
- 다른 광고 네트워크(미디에이션)를 붙이면 그 네트워크가 주는 줄을 추가한다.
